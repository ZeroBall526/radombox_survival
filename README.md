# RandomBox

### 랜덤조합 플러그인
마인크래프트에서 모든 아이템 조합 결과가 랜덤 상자로 바꿔주는 플러그인입니다.

---

* ### features
  * 랜덤 상자 생성 
  * 플레이어 인벤토리에서 아이템 조합, 아이템 제작대 조합시 랜덤상자 지급
  * 철도구 제작시 랜덤 장비 상자 지급
  * 야생의 기본이 되는 목재, 막대기, 작업대, 버튼(너무 날먹임)은 제작가능 함
* ### supported mc-versions
  * 1.21

* ### supported bukkit
  * paper
  * ! 이외의 다른 버킷에서 구동을 보장하지 않습니다 !
